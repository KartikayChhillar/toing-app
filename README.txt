TOING FINAL APP
Open toing_final_app.html in Chrome/Edge.

Demo flow:
Home -> Reels -> Play YouTube food video -> Add to batch -> Choose pickup -> Confirm
Home -> VEG -> categories/search -> add food
Pass -> choose Lite/Standard/Full

The UI uses embedded local food assets so the interface stays visible even if an external video is unavailable.
YouTube videos load only after tapping Play, preventing the black-screen issue caused by failed/autoplaying embeds.
